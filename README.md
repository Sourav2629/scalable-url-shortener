# Scalable URL Shortener Platform

A production-ready URL Shortener Platform built to demonstrate backend engineering, system design, scalability, caching, asynchronous processing, and cloud-ready architecture.

## Project Status

🚧 Planning Phase

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Redis
- BullMQ
- Docker
- React
- Tailwind CSS

## Goals

- Build production-quality backend architecture.
- Learn system design from scratch.
- Implement scalable URL shortening.
- Add analytics and background processing.
- Deploy using Docker and cloud services.
- Prepare for SDE interviews.

---

This project is being built incrementally following software engineering best practices.
